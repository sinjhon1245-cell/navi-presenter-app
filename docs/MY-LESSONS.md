# 내 수업: 여러 수업 저장 (2026-11-11, PRD v0.2 3-1 · 3-2 · 3-3 · 4)

교사가 만든 수업을 여러 개 두고 열고 · 복제하고 · 지워요. 예시 수업은 원본을 그대로 두고, 고치려면 내 수업으로 복제해요.
**수업 진행 엔진은 바꾸지 않았어요**: 화면에 연 수업은 예전처럼 `D` 하나이고, 휴대폰이 읽는 지금 수업 `lessons/deck` · 세션 `sessions/s{PIN}` · 수업 복구 `navi-run` · 기록은 그대로예요.

## 1. 화면

| 화면 | 무엇 |
| --- | --- |
| **내 수업**(처음 화면, 2026-11-14 개편 · 아래 1-1) | 머리 막대 없음. 제목 · 저장 위치 한 줄, ‘새 수업 만들기’ · ‘PDF · PPTX로 시작하기’ · ‘예시 수업 활용하기’, 파일 원본 · 수업 내용이 어디에 저장되는지 한 줄(‘파일 옵션’ 안에 수업 시간 · 공유 링크), 새로 고친 순서의 목록. 줄 전체를 누르면 열리고, 복제 · 삭제(확인 줄)는 줄의 ⋯ 메뉴 |
| **예시 수업**(따로 둔 메뉴) | 예시 5개(학년 · 교과 거르기, 목록 · 갤러리). ‘이 예시로 수업하기’(원본 그대로) · ‘수정해서 사용하기’(내 수업으로 복제) |
| **새 수업** | 누르면 바로 고치는 화면. 제목 ‘새 수업’, 빈 장면 1개, 학년 · 교과는 비어 있어요(선택). 도입 · 전개 · 정리를 미리 만들지 않아요 |
| **장면 편집** | ‘+ 장면 추가’는 늘 마지막 뒤. 위 · 아래 단추로 순서. ‘복제’는 바로 아래(발화 · 개념 · 메모 · 그 장면의 자료를 새 사본으로). 지우기는 확인 줄, 자료는 보관함으로, 장면이 하나면 못 지워요 |
| **예시 원본** | 읽기 전용: 글자 칸은 읽기만, 장면 · 자료 단추 없음, 저장 표시 ‘예시 원본’, 위에 ‘수정해서 사용하기’. 원본으로 수업 · 미리보기는 그대로 돼요 |
| **수업 이름 줄**(내 수업만) | 수업 이름 · 학년(선택 안 함 · 1–6) · 교과(선택), 예시에서 복제했으면 ‘예시 ‘…’에서 복제’ |

‘추천’ · ‘발견하기’ 같은 메뉴는 없어요. 교사 간 공유도 만들지 않았어요.

### 1-1. 내 수업 첫 화면 개편 (2026-11-14, 설계안 2판 · `feature/my-lessons-ux`)

- **머리 막대는 내 수업에만 없어요**(`viewSetup()`이 `onMyLib()`일 때 `setupBar()`를 그리지 않음, `setupBar()`는 그대로). 수업 시작 · 수업 미리보기 · 휴대폰 연결 · 진행 중인 수업으로 · 처음부터 다시는 수업 준비 · 예시 수업 · 수업 기록 · 발표 설정 화면의 머리 막대에 그대로 있어요. 내 수업으로 오면 열려 있던 휴대폰 연결 창은 닫아요(PIN 자리는 닫을 때처럼 정리).
- **강한(보라) 단추는 화면에 하나**: 평소 ‘새 수업 만들기’, 끝나지 않은 수업이나 다른 기기의 진행 중인 수업이 있으면 그 알림의 단추(‘이어서 하기’ · ‘이 기기에서 이어서 진행하기’)이고 ‘새 수업 만들기’는 테두리 단추. 처음 이름 묻기 · 다른 기기가 준비 중일 때의 단추는 내 수업에서 보통 단추예요.
- **최근에 연 수업과 끝나지 않은 수업은 따로**: ‘최근에 연 수업’(`navi-last`)은 그 줄 둘째 줄의 글자 하나(단추 없음). 끝나지 않은 수업(`navi-run`)은 맨 위 알림 한 곳(문구 · 단추 · 확인 줄 그대로) + 그 줄의 ‘끝나지 않은 수업 · 3 / 9’. 다른 기기에서 진행 중인 수업은 그 줄에 ‘수업 중 · 3 / 9’. ‘지금 수업 · 계속 준비하기’ 줄과 줄의 보라 ‘지금 수업’은 없앴어요(지금 연 줄은 `.mrow.on`으로만 남아요).
- **줄**: 제목 → 학년 교과 · 장면 수 · 분 · 고친 날 · 예시에서 복제 · 파일(‘PDF에서’, 원본이 이 브라우저에 없으면 ‘PDF 원본은 처음 올린 PC에’). 지난 수업이 있으면 오른쪽에 날짜와 신호별 장면 수(색 점 + ‘다시 설명 1 · 더 확인 2 · 잘 이해 3’). 줄 높이 PC 62px · 휴대폰 60px 이상. ⋯ 메뉴(열기 · 복제 · 삭제)는 Esc · 밖을 누르면 닫히고 초점은 ⋯로 돌아와요.
- **파일**: ‘PDF · PPTX로 시작하기’는 지금의 파일 고르기(`#pdf-in`)를 열어요. 내 수업 화면 어디에 끌어다 놓아도 돼요. 안내 한 줄: 로그인하면 “PDF · PPTX 원본은 이 브라우저에, 장면 글자는 계정에 저장돼요”, 아니면 “원본과 수업 모두 이 브라우저에”. 저장 방식(IndexedDB `navi-files`)은 그대로이고, 줄의 원본 표시는 파일 id가 이 브라우저에 있는지 읽기만 해요.
- **계정 자리**(모든 준비 화면, `acctSpot()` · `acctPop()`): PC는 왼쪽 메뉴 맨 아래(기기 상태 아래). 로그인 전에는 ‘구글로 로그인’ + ‘로그인 유지’, 로그인하면 표시 이름과 ‘구글 계정’만(이메일은 계정 메뉴 안에만 · 준비 화면을 TV에 띄울 수 있어서). 계정 메뉴: 이름 바꾸기(발표 설정의 이름 칸으로) · 로그아웃(수업 중이면 지금처럼 확인 줄). 접은 메뉴 · 태블릿은 동그라미 하나, 메뉴는 64px 메뉴 오른쪽에. 휴대폰은 준비 화면 위쪽 52px 머리 줄(서비스 이름 + 동그라미 · 로그인 전에는 ‘로그인’), 계정 메뉴는 아래에서 올라와요. **교사 화면(수업 진행) · 모바일 리모컨 · 수업 화면에는 계정 자리가 없어요.**
- **휴대폰 다섯 칸 메뉴**: 같은 너비 다섯 칸에 짧은 이름(내 수업 · 예시 · 준비 · 기록 · 설정), 높이 44px. 320 · 360 · 390에서 잘리지 않아요. 탭 이름(`aria-label`)은 전체 이름 그대로예요. 내 수업의 두 단추도 휴대폰에서는 짧은 글자(새 수업 · PDF · PPTX), 이름은 전체 그대로.
- 알림 두 개(`runOfferLine` · `ctlLine`)는 내 수업에서만 짧은 줄 모양(`.on-lib`). 다른 기기가 준비 중일 때는 회색, 진행 중 · 끝나지 않은 수업은 주황. 문구와 제한(‘이 기기에서 고친 내용은 이 브라우저에만 남아요’)은 숨기지 않아요.

## 2. 저장

| 언제 | 어디 |
| --- | --- |
| 구글로 로그인한 교사 PC | 계정 `teachers/{UID}/decks/{수업 id}`(Firestore). 같은 계정의 다른 PC에서 같은 목록 |
| 로그인 안 함 · Firebase 없음 | 이 브라우저 IndexedDB `navi-local`(로그인한 교사가 이 기기에서만이면 `navi-local-{UID}`)의 `lessons`, id `m-…` |
| 휴대폰 | 목록을 읽지 않아요. 지금 수업 `lessons/deck`만 따라가요(규칙도 기기에게 `decks`를 열지 않아요) |

- 수업 하나 = 지금 수업 문서와 같은 모양 + `kind: "mine"` · `myId` · `key: "mine:{id}"` · 예시에서 복제했으면 `from`(예시 id) · `oldKeys`(예시의 지난 기록을 이어 봐요). 계정 문서에는 `at`(고친 시각) · `made`(만든 시각)도.
- 수업 id: 브라우저 암호 난수 `m-` + 16진수 16자리.
- 고치면 0.4초 뒤 저장해요. 바뀐 게 있을 때만 쓰고(열기만 해서는 쓰지 않아요), 다른 수업으로 바꾸기 직전 · 로그아웃 직전에는 기다리던 저장을 먼저 끝내요(로그아웃은 5초까지 기다려요). 지운 수업은 기다리던 저장을 버려서 다시 살아나지 않아요(2026-11-11, PR #12 CI에서 찾음).
- 올린 파일(PDF · PPTX · 그림)은 이 브라우저의 파일 저장소(IndexedDB `navi-files`)에 두고, 내 수업에는 파일 id만 남겨요(2026-11-11, `docs/LOCAL-FILES.md`). PDF · PPTX로 시작하면 바로 내 수업이 돼요. 파일을 저장할 수 없는 브라우저(사생활 보호 창 등)에서는 예전처럼 그 링크를 빼고 ‘파일은 다시 넣어 주세요’로 남겨요.
- 마지막에 연 수업은 이 브라우저에 `navi-last`(로그인하면 `navi-last-{UID}`)로 적어 두고, 다음에 열 때 ‘내 수업’ 뒤에서 지금 수업으로 다시 열어요.

## 3. 다른 PC · 수업 중

- 수업을 맡지 않은 PC는 예전처럼 지금 수업 · 세션을 쓰지 않아요(`sendOwn`). 그 PC에서 새 수업을 만들거나 고치면 **내 수업에만** 저장되고, 진행 중인 수업 · 휴대폰은 그대로예요(`tests/library.spec.js`).
- 다른 PC가 지금 가르치는 바로 그 수업은 이 PC가 고쳐도 계정에 저장하지 않아요(가르치는 PC의 내용을 덮지 않게). 이 경우만 따로 시험하지는 않았어요.
- 같은 수업을 두 PC에서 동시에 고치면 나중에 저장한 쪽이 남아요(STAGE1-DESIGN 1과 같아요).
- 수업 중에는 이 PC의 ‘내 수업’ · ‘예시 수업’으로 가지 못해요(예전과 같아요). 지우기도 지금 수업 중인 수업은 막아요.

## 4. 예전 데이터 (지우지 않아요)

| 예전 데이터 | 지금 |
| --- | --- |
| 이 브라우저에서 고친 예시(0.6 · 0.7, `lessons`의 예시 id 줄 `edited` · `deck`) | 예시는 원본으로 열려요. 고친 내용은 ‘내 수업’에 **‘예전에 고친 예시 · 이 브라우저’**로 보이고, 열면 내 수업으로 옮겨요. 원래 줄은 지우지 않고 `movedTo`(옮겨 간 수업 id)만 적어요 |
| 로그인하기 전에 만든 내 수업(`navi-local`) | 로그인해도 저절로 올리지 않아요. 기록 화면의 ‘이 계정으로 가져오기’(예전 기능, 사본 + 원본에 `claimedBy`) 뒤 ‘내 수업’에 **‘이 브라우저에만 있어요’**로 보이고, 열면 같은 id로 계정에 저장, 이 계정 칸의 줄에 `movedTo` |
| 계정의 지금 수업 `lessons/deck` | 그대로(지우거나 옮기지 않아요). 휴대폰이 읽는 지금 수업 문서로 계속 써요. 규칙이 `kind: "mine"` · `myId` · `from`을 받게만 넓혔어요 |
| 수업 기록(`navi-local…`의 `records`) | 그대로. 내 수업을 지워도 기록은 남아요. 복제본은 예시의 지난 기록(`oldKeys`)을 이어 봐요 |
| 수업 복구 사본 `navi-run` | 그대로. 내 수업으로 가르치던 수업은 사본에 그 수업의 글자를 담아 두어 ‘이어서 하기’로 돌아오고, 다시 고치기 전에는 계정에 다시 쓰지 않아요 |

## 5. 보안 규칙 (`firestore.rules`)

- `match /teachers/{uid}/decks/{id}`: 읽기 · 지우기 = 본인(`isOwner`), 만들기 · 고치기 = 본인 + id `m-[0-9a-f]{16}` + `validMine`(지금 수업과 같은 칸 + `at` · `made`, `kind == 'mine'`, `myId == id`, 장면 1–100개).
- 지금 수업 `validDeck`: `kind`에 `mine`, 칸에 `myId` · `from`을 더했어요(나머지 검사는 그대로, `deckFields`로 함께 써요).
- 다른 교사 · 같은 UID의 다른 로그인 방식 · 허용받은 PIN 휴대폰 · 익명 · 로그인 안 함은 `decks`를 읽지도 쓰지도 못해요(`tests/rules.spec.js`).
- 운영 프로젝트에는 배포하지 않았어요. Firebase 서버 문법 검사만 했어요(통과).
