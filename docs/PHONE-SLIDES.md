# 휴대폰 슬라이드: 확인한 것만 말하기 (2026-11-19, PR #26)

4단계 실제 40분 수업 검증의 MEDIUM 1. PDF+PPTX로 만든 수업에서 같은 계정 휴대폰이 ‘슬라이드는 교사 PC에 있어요. Drive의 사본으로 이 휴대폰에서도 볼 수 있어요’와 ‘슬라이드 보기’를 보여 줬어요. 누르면 Google 허용 창이 뜬 뒤 ‘사본이 Drive에 없어요. 교사 PC에서 ‘PDF 사본 남겨 두기’로 바꾸면…’만 나왔어요(PDF+PPTX 수업에는 바꿀 것이 없어요). 장면 이동 · 노트 · 신호는 그때도 됐어요.

## 원인

- **구조**: 수업 파일은 교사 PC 브라우저(IndexedDB)에만 있어요. 휴대폰이 읽는 수업 문서(`lessons/deck`)에는 파일의 id · 종류 · 이름만 있고(규칙 `validFile`이 그 셋만 허용), Drive 사본이 있는지는 적혀 있지 않아요. 사본은 Google로 바꾸며 ‘PDF 사본 남겨 두기’를 고른 수업에만 있어요(같은 지문 `appProperties.fid`). 그래서 휴대폰은 **Drive에 물어보기 전에는 사본이 있는지 몰라요.**
- **표시 조건**: 그런데 화면은 확인하기 전부터 볼 수 있는 것처럼 말했어요(‘슬라이드 보기’). 없다고 확인한 뒤의 안내도 Google 변환 수업 기준이었어요.

수업 문서에 ‘사본 있음’ 표시를 더하면 규칙(`validFile`)을 바꿔야 해서 운영 규칙 배포가 먼저 필요해요. 또 그 표시는 교사 PC가 아는 것이라, 다른 PC에서 만든 사본이나 Drive에서 지운 사본은 맞지 않아요. 이번에는 데이터 · 규칙을 그대로 두고 화면이 확인한 것만 말하게 했어요.

## 바뀐 것

| 상태 | 전 | 후 |
| --- | --- | --- |
| 확인 전 | ‘Drive의 사본으로 이 휴대폰에서도 볼 수 있어요’ + **슬라이드 보기** | ‘슬라이드 그림은 교사 PC에 있어요. Google로 바꾸며 사본을 남긴 수업이면 Drive에서 찾을 수 있어요.’ + **Drive에서 슬라이드 찾기** |
| 찾는 중 | ‘Google Drive에서 슬라이드를 받는 중이에요…’ | ‘Drive에서 이 수업의 슬라이드를 찾는 중이에요…’ |
| 사본 없음 | 두 문장(‘교사 PC에서 … 바꾸면 보여요’) | **한 줄**: ‘Drive에 이 수업의 슬라이드 사본이 없어요.’ 누를 것 없음. 이 탭에서는 같은 수업(파일 지문)을 다시 찾지 않아요(새로고침해도, `sessionStorage navi-gs-none`) |
| 사본 있음 | 지금 장면 크게 · 다음 장면 작게 · 노트 | 그대로 |
| Google 창을 닫음 | ‘…바꾸지 않았어요. 아무것도 Drive로 가지 않았어요.’(변환 문구) + 슬라이드 보기 | ‘Google 창을 닫아서 찾지 않았어요.’ + **다시 찾기**. 저절로 다시 열지 않아요 |
| 팝업 막힘 · 다른 계정 | 변환 문구 | ‘Google 창이 막혔어요…’ · ‘교사와 다른 구글 계정을 골랐어요…’ + 다시 찾기 |
| Drive 허용 없음(403) | 같은 열쇠로 다시 시도해 또 실패 | ‘Drive 허용을 받지 못했어요. Google 창에서 ‘Drive 파일’에 체크해 주세요.’ + 다시 찾기. 그 열쇠는 버려서 다음에는 Google 창이 다시 떠요 |
| 허용 시간 지남(401) | ‘확인 전’으로 | ‘Google 허용 시간이 지났어요.’ + 다시 찾기 |
| 사본이 수업과 다름 | 변환 문구 | ‘Drive의 사본이 지금 수업과 달라요. 슬라이드는 교사 PC에서 봐요.’(다시 찾아도 같아서 단추 없음) |

이번 시간에 이미 허용한 휴대폰은 예전처럼 창 없이 저절로 찾아요(없으면 한 줄만).

## 그대로인 것

- 휴대폰은 Drive를 읽기만 해요. 올리거나 고치거나 지우지 않아요(시험이 휴대폰의 Drive 요청이 모두 GET인지 봐요).
- 사용자 동의 없이 Drive에 새로 올리지 않아요. 사본은 교사 PC의 ‘동의하고 바꾸기’ 때만 생겨요(PR #22).
- 다른 기기의 로컬 정보로 단정하지 않아요. ‘없음’은 이 휴대폰이 Drive에 물어본 답이고, 그 답도 이 탭에만 둬요.
- 수업 문서 · 규칙 · Firestore는 그대로예요.
- 장면 이동 · 노트 · 신호는 어느 상태에서도 그대로예요.

## 시험

`tests/gslides.spec.js`(에뮬레이터 + 가짜 Google):
- PDF+PPTX 수업: 확인 전 문구 · ‘슬라이드 보기’ 없음 · 누르기 전 Google 요청 없음 → 찾기 → 한 줄 · 단추 없음 → 다음 장면 · 휴대폰 새로고침 뒤에도 다시 찾지 않고 Google 창도 열지 않음. 넘기기 · 노트 · 신호.
- Google 변환(사본 남김): Google 창 닫기 → 까닭 · 다시 찾기 · 저절로 다시 열지 않음 · Drive 요청 없음 → 403 → 까닭 · 열쇠 버림 → 다시 허용 → 사본으로 슬라이드. 넘기기 · 노트 · 신호.
- Google 변환(사본 남기지 않음) + 이번 시간에 이미 허용: 창 없이 저절로 찾고 한 줄만.
- 예전 시험(사본 있음 → 슬라이드)은 단추 이름만 바꿨어요.
