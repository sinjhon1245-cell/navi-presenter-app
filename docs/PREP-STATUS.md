# 수업 준비 위쪽: 한 상태 영역 (2026-11-16, PR #24)

올린 직후 수업 준비 위쪽에 안내가 다섯 칸 쌓여(이름 정하기 · 시작 전 확인 · 올리기 결과 · 기본 정리 · 확인할 장) 1366×768에서는 슬라이드가 515px 아래, 1280×590에서는 첫 화면 밖이었어요(3단계 UX 진단). 이제 한 영역(`prepStatus`)으로 묶어요.

## 순서(위에서 아래로)

1. **칩 한 줄**: 자료 방식(PDF 그림 · PDF 그림 · PPTX 노트 · Google 변환 · Google 그림(큰 파일)) · `노트 n / 전체` · `확인할 장 n`(찾은 것이 있을 때, 누르면 펼침) · 수업 화면 · 모바일 리모컨(예전 ‘시작 전 확인’ 줄, `.ready`, 1440px보다 좁으면 작은 설명은 마우스를 올리면) · `자세히 ▾`(`aria-controls="pst-detail"`, 펼쳐도 초점은 그 단추). PPTX만이면 자료 방식 칩 자리에 경고 칩 ‘글자 화면 · 원본 디자인 아님’과 ‘원래 모양으로 [Google로 원래 모양 만들기] [PDF 넣기]’(`.words-only`)가 같은 줄에 들어가요(따로 한 줄을 차지하지 않게).
2. **진행 중**: 올리는 중 · 장을 그림으로 바꾸는 중(진행 막대), 분석 중(멈추기).
3. **조치가 필요한 것만, 급한 순서**: 오류(`.pst-err`) → 노트를 붙일지 묻기(`.notes-ask`) → 노트를 붙이지 않았어요(`.pair-warn`, 새로고침해도 남음) → 파일이 이 브라우저에 없어요(`.file-need`).
4. **결과 한 줄**: 방금 올린 결과. 닫을 수 있어요(×). 닫아도 위 경고와 칩은 그대로예요.
5. **자세히(접힘)**: 이 방식의 한계(일반 한계) · 이 자료에서 찾은 것(실제로 감지한 장, 누르면 그 장면) · 기본 정리 설명.

처음 로그인의 표시 이름은 얇은 한 줄(입력 · ‘이 이름으로 시작’). 예전처럼 저장할 때까지 남고, 저장하지 않아도 올리기 · 수업 · 기록은 그대로 돼요(이름은 계정 표시에만 쓰이고, 없으면 구글 이름). 팝업으로 하면 이름을 정하기 전까지 모든 것을 막고, ‘나중에’로 숨기면 다음 로그인마다 다시 떠서 둘 다 쓰지 않았어요.

## 노트를 붙일지 묻는 중에 창이 닫히면(PR #24 검토, 2026-11-16)

PDF와 PPTX가 같은 자료인지 확실하지 않아 묻는 동안(두 파일을 함께 올렸을 때, PDF 수업에 ‘PPTX에서 노트 붙이기’를 했을 때) 이 브라우저에 `notesOff: "ask"`를 적어 둬요. 묻는 줄은 창에만 있어서 새로고침 · 다른 수업을 열었다 오면 사라지지만, 그 뒤에는 경고 줄 ‘노트를 아직 붙이지 않았어요. 같은 자료인지 고르기 전에 멈췄어요. PPTX를 다시 고르면 장을 비교해 물어봐요. [PPTX에서 노트 붙이기]’(`.pair-warn.notes-wait`)가 남아요. 노트는 저절로 붙지 않고, 다시 고르면 같은 비교로 다시 물어요. ‘노트 붙이기’면 사라지고, ‘붙이지 않기’는 교사의 답이라 더 묻지 않아요(노트 칸의 ‘+ PPTX에서 노트 붙이기’는 그대로). 글자 화면 PPTX 수업에 PDF를 넣을지 묻던 중이면 PDF를 넣지 않고 글자 화면 경고와 ‘원래 모양으로 [PDF 넣기]’가 그대로예요.

## 손가락으로 누르는 칸(PR #24 검토, 2026-11-16)

휴대폰(760px 이하)에서 상태 영역의 칩 · ‘자세히’ · 시작 전 확인 · 변환 · 노트 · 닫기 단추는 보이는 크기 · 자리는 그대로 두고 보이지 않는 칸만 44px로 넓혔어요(`::after`). 슬라이드는 내려가지 않아요(390×844에서 PDF+PPTX 341px · PPTX만 409px 그대로). 이웃 칸과 겹치지 않게 ‘자세히’ 위만 12px 띄웠어요(슬라이드 아래쪽). 잰 보이는 크기(390×844): 확인할 장 81×30 · 자세히 60×28 · 시작 전 확인 103×28 · 141×28 · PDF 넣기 75×40 · 장면 단추 · 확인했어요 40 · 닫기 40×40 → 누를 수 있는 칸은 모두 44px 이상. 시험은 칸의 네 끝을 눌러 그 단추가 눌리는지 봐요(`touchMisses`). 태블릿은 칩 줄 사이가 좁아 넓히면 이웃과 겹치거나 슬라이드가 내려가서 이번에는 그대로예요.

## 휴대폰(760px 이하)

슬라이드가 먼저예요. 수업 머리(수업 시작) → 꼭 볼 것(진행 중 · 오류 · 노트 묻기 · 노트 안 붙임 · 파일 없음 · 글자 화면 경고와 원래 모양으로) → 장면 목록 → **슬라이드** → 장면 이름 · 단추 → 노트 → 칩 줄 · 결과 · 자세히 → 지난 수업 → 수업 정보. 글자 크기 · 누르는 칸은 그대로예요.

## 측정(같은 시나리오, 슬라이드 시작 · 첫 화면에 보이는 높이)

| 화면 | PDF+PPTX(로그인 안 함) | PPTX만(로그인 안 함) | 로그인 + Google 변환(에뮬레이터) |
| --- | --- | --- | --- |
| 1366×768 | 410 → 324px, 다 보임 | 515 → 342px, 253 → 336/336 | 654 → 373px, 114 → 336/336 |
| 1280×590 | 410 → 324px, 180 → 266/288 | 536 → 342px, 54 → 248/288 | 654 → 373px, 0 → 217/288 |
| 390×844 | 1050 → 341px, 0 → 201/201 | 1179 → 409px, 0 → 201/201 | 912 → 466px, 0 → 201/201 |

로그인 안 함의 ‘전’은 정식 사이트(b66ffdb), ‘후’는 이 PC(Firebase 꺼짐)라 휴대폰 머리의 ‘휴대폰 연결’ 단추 하나만큼 차이가 나요. 로그인 + Google은 같은 에뮬레이터에서 main과 이 브랜치를 비교했어요. 경고 상태(1280, 노트 불일치): 5 → 171px, Google 실패: 0 → 161px(경고는 그대로 보임).

## 방식별 안내(일반 한계 · 실제로 찾은 것)

| 방식 | 칩 | 일반 한계(‘자세히’) | 실제로 찾은 것 |
| --- | --- | --- | --- |
| PDF만 | PDF 그림 n장 | 장마다 한 장의 그림, 애니메이션 · 전환 · 동영상 · 소리 재생 안 됨 | 없음(PDF만으로 애니메이션을 추정하지 않음) |
| PDF + PPTX | PDF 그림 · PPTX 노트 n장 | 같음 + 노트는 PPTX에서 | PPTX에서 애니메이션 · 동영상 · 소리가 있는 장(`pptxScan`) |
| PPTX만 | 글자 화면 · 원본 디자인 아님(경고색) | 그림 · 도형 · 표 · 차트 · 글꼴 · 배치가 학생에게 보이지 않음, 효과 재생 안 됨 | — (늘 경고 줄) |
| Google 변환 | Google 변환 n장 | Google이 다시 그림: 글꼴 · 배치 · 차트 · SmartArt가 다를 수 있음, 효과 재생 안 됨 | 차트 · SmartArt · 수식 · 애니메이션 · 동영상 · 소리 · 워드아트 장, Google에 없는 글꼴(`gsPrep`) |
| Google 그림(큰 파일) | Google 그림(큰 파일) n장 | 1600px 그림이라 아주 작은 글자 · 일부 기호가 흐리거나 빠질 수 있음 | Google 변환과 같음 |

- 전환은 거의 모든 장에 있어 ‘찾은 것’에 넣지 않고 일반 한계로만 말해요.
- ‘확인했어요’를 눌러도 목록은 ‘확인한 장’으로 남아요(해결된 것처럼 사라지지 않음).
- 수업 시작 단추 옆 줄(`sbar-sub`)에 한 마디: ‘글자 화면 · 원본 디자인 아님’ 또는 ‘확인할 장 n’(확인 전).
- 방식 · 노트 불일치 · 찾은 것은 이 브라우저에 계정별로(`navi-src`, Google은 `navi-gs-review`) 저장해요. 다른 PC에서는 파일 종류로만 말해요. Firestore · 규칙은 그대로예요.

## 수업 끝 기록 시트

- ‘수업 기록 보기’가 주 단추(PC 48px, 휴대폰은 폭 가득 52px). 기록이 저장되기 전에는 ‘기록을 저장하는 중…’(누를 수 없음), 저장할 수 없으면 ‘기록을 저장하지 못했어요’.
- 그 기록이 이 기기에 아직 없으면(휴대폰 · 계정 저장 전) 빈 기록 화면으로 가지 않고 그 자리에서 말해요. 같은 계정이 아닌 휴대폰은 ‘기록은 교사 PC에서 볼 수 있어요’.
- 수업 흐름 칸의 장면 이름은 줄임표 대신 두 줄까지.

## 시험

`tests/prep-status.spec.js`(여섯 크기): PDF만 · PDF+PPTX(효과 자료 `anim.pptx` · `anim.pdf`, 직접 만든 것) · PPTX만 · 노트 불일치(새로고침 뒤에도) · 파일 없음 · 시작 → 끝 → 기록. `tests/gslides.spec.js`: Google 성공 · 실패 · 취소, 표시 이름 한 줄, 휴대폰 폭의 변환 · 동의 단추 칸, 동의 창이 다시 그려져도 ‘다음부터는 묻지 않고’ 체크가 남고 닫으면 저장하지 않음(CI에서 찾은 것). `tests/prep-status.spec.js`에 노트 묻는 중 새로고침(셋) · 휴대폰 누르는 칸.
