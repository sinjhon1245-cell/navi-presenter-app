# 영상 재생 제어 (2026-11-11, 2026-11-12 ‘다음’ 두 단계 보완)

YouTube 영상을 수업 흐름에 넣었어요. 영상은 **장면 하나**(장면 영상)로도, 예전처럼 **수업 자료**(학생 화면에 띄우기)로도 써요.
학생 화면에는 멈춘 채 뜨고, 영상 장면의 **첫 ‘다음’은 영상 재생, 둘째 ‘다음’은 다음 장면**이에요(교사 PC · 휴대폰 같음). 일시정지는 교사 PC에서 해요.
진행 엔진은 그대로이고, 세션 문서에 작은 칸 `vid` 하나를 더했어요(1-1).

## 1. 요구와 구현

| 요구 | 어떻게 |
| --- | --- |
| 1. 영상 장면에 들어가면 자동 재생하지 않고 멈춤 | 삽입 주소에 자동 재생을 넣지 않아요. YouTube의 멈춘 첫 화면이 떠요. 교사 화면 영상 줄은 ‘일시정지’ |
| 2. 교사 PC에서 재생 · 일시정지 · 다음 장면 | **첫 ‘다음’ = 재생, 둘째 ‘다음’ = 다음 장면**(1-1). 교사 화면의 학생 화면 미리보기 아래 **영상 줄**: 재생 / 일시정지 단추(키 **K**), 상태, 재생 시간 |
| 3. 다시 그리기 · 신호등 · 휴대폰 조작으로 처음부터 재생되지 않음 | 학생 화면은 예전 `paint` · `keepFrame`으로 영상 칸을 그대로 둬요. 영상 칸 주소는 영상이 화면에 있는 동안 바뀌지 않아요 |
| 4. 재생 중 다음 장면으로 가면 5초 동안 되돌리기(장면 이동 취소) | 교사 화면 아래쪽에 ‘이전 장면으로 되돌리기 · 5초’(키 **U**). 누르면 장면 · 들어간 시각 · 장면 기록이 넘기기 전으로 돌아가요(넘긴 장면에 머문 몇 초가 기록에 남지 않아요). 영상을 되감지 않아요 |
| 5. 이전 영상 장면으로 돌아오면 위치 보존 · 멈춘 채 | 떠날 때 마지막 재생 위치를 기억하고, 돌아오면 그 위치(초, 내림)부터 멈춘 채 떠요. 되돌리기 · 이전 키 · 목차 · 휴대폰 모두 같아요 |
| 6. 영상이 끝나도 다음 장면으로 자동 이동 안 함 | 아무것도 넘기지 않아요. 교사 화면은 “영상이 끝났어요 · 다음 장면으로 저절로 넘어가지 않아요”, ‘처음부터 다시’ 단추. 학생 화면은 YouTube 끝 화면(다른 영상 추천)을 가려요 |
| 7. YouTube 삽입 정책 · 자동 재생 제한 | 4절 |

영상 자료(장면의 수업 자료로 띄운 영상)도 같아요: 띄우면 멈춘 채, 다음 키로 내리면(재생 중이었으면) 5초 동안 ‘영상 다시 띄우기’, 다시 띄우면 멈춘 곳부터.
영상 자료의 ‘다음’은 예전 확정 정책대로 **내리기**예요(학생 화면에 띄운 자료는 다음 키 한 번에 닫히고 슬라이드로, SPEC ‘꺼내고 돌아오기’). 재생은 영상 줄 · K로 해요.

### 1-1. 영상 장면의 ‘다음’ 두 단계(2026-11-12 확정 정책)

| 입력 | 영상 장면에 들어온 뒤 첫 ‘다음’ | 그다음 ‘다음’ |
| --- | --- | --- |
| 교사 PC: → · ↓ · 스페이스 · 엔터 · PageDown · N · 클리커 · 큰 단추 · 학생 화면 누르기(영상 밖) | 영상 재생(장면 그대로) | 다음 장면(재생 중이었으면 5초 되돌리기) |
| 휴대폰(같은 계정): 큰 단추 | 영상 재생(세션에 `vid`를 쓰면 교사 PC가 학생 화면 영상을 틀어요) | 다음 장면 |
| 휴대폰(PIN): 큰 단추 | 영상 재생(명령 `vid`를 남기면 교사 PC가 지금 수업과 맞는지 보고 적용) | 다음 장면 |

- 큰 단추 글자가 미리 말해요: ‘영상 재생’(마지막 장면이면 ‘마지막 장면 · 영상’) → ‘다음 · 다음 장면 이름’.
- **이번 방문**만 세요: 다른 장면에서 돌아오면(되돌리기 · 이전 키 · 목차 · 휴대폰) 다시 멈춘 채이고 첫 ‘다음’은 멈춘 곳부터 재생해요.
- K · 재생 단추 · TV 화면을 직접 눌러 먼저 틀었으면, 교사 PC가 `vid`를 적어 그다음 ‘다음’은 바로 다음 장면이에요(휴대폰도 같아요).
- 삽입 금지처럼 재생할 수 없는 영상은 교사 PC가 `vid`를 적어 ‘다음’이 바로 다음 장면이에요(되는 척하지 않아요).
- 일시정지는 교사 PC에서만(영상 줄 · K). 일시정지한 뒤의 ‘다음’은 다음 장면이고, 멈춘 채 넘겼으니 되돌리기는 뜨지 않아요.
- 화면 가리기 · 번호 뽑기 · 띄운 자료가 있으면 ‘다음’은 예전처럼 그것부터 닫아요.
- 수업 미리보기에서도 두 단계가 같아요(학생 화면에는 나가지 않아요).
- **세션 칸 `vid`** = `{ k: "s:장면 id", at }`: 이번 방문에서 그 장면 영상을 틀었거나 틀어 달라고 했다는 표시. 장면이 바뀌면 `null`(`patchS`가 장면이 바뀔 때 표시가 있으면 지워요). 학생 화면을 그리는 기기(교사 PC)는 **새로 본** 표시에만 재생해요: 새로고침 · 학생 화면 창을 다시 열 때 이미 있던 표시로는 저절로 재생하지 않아요.
- **보안 규칙**(`firestore.rules` `validSession`): `vid`는 없음 · `null` · `{ k: 문자열 120자 이하, at: 숫자 }`만. 이 저장소 파일만 바꿨고 **운영 규칙에는 배포하지 않았어요.** 운영에 올릴 때는 교사 승인 뒤 **규칙을 먼저**, 그다음 앱이에요. 규칙 없이 앱만 올리면 휴대폰의 ‘영상 재생’ 쓰기가 거절돼 휴대폰 화면이 원래대로 돌아오고(교사 PC의 ‘다음’은 그대로 돼요), 장면 이동은 그대로 돼요(표시가 없으면 지우는 쓰기도 하지 않아요).

## 2. 구조

- **장면 영상**: 수업 준비의 장면 편집에 ‘장면 영상(YouTube 링크)’ 칸. 장면에 `video`(링크 문자열)로 저장해요(내 수업 · 계정 문서의 장면 안, 규칙은 장면 안쪽을 보지 않아서 바꾸지 않았어요). YouTube 주소(youtube.com · youtu.be · shorts · live)만 받고, 링크의 시작 시각(`t=90` · `t=1m30s` · `start=`)을 써요. 비우면 영상이 빠져요.
- **삽입 주소**: `https://www.youtube-nocookie.com/embed/{id}?rel=0&enablejsapi=1&playsinline=1&iv_load_policy=3&origin={이 사이트}`(+ `start=`). 자동 재생 값은 넣지 않아요.
- **제어**: YouTube 삽입 플레이어의 메시지(`listening` → `onReady` · `infoDelivery` · `onStateChange` · `onError`, 명령 `playVideo` · `pauseVideo` · `seekTo`)를 직접 주고받아요. YouTube 스크립트(`iframe_api`)는 불러오지 않아요. 학생 화면 창은 교사 화면 페이지가 그리는 별도 창이라, 영상의 답이 그 창으로 오기 때문에 그 창에 직접 귀를 기울여요. 받는 메시지는 YouTube 주소에서 온 것, 그 영상 칸에서 온 것만 받아요.
- **상태는 교사 PC 메모리에**: 지금 영상(`vidOn`: 상태 · 시간 · 길이)과 영상마다 멈춘 곳(`vidPos`). 세션에는 ‘이번 방문에 틀었는지’(`vid`, 1-1)만 가요. 재생 위치 · 상태는 쓰지 않아요.
- **되돌리기**: 학생 화면을 그릴 때마다 지난번 상태와 비교해요(`vidSeen`). 재생 중이던 영상이 장면 이동 · 자료 내리기로 사라지면 5초 동안 되돌리기를 보여 줘요. 누가 넘겼든(교사 PC · 학생 화면 누르기 · 같은 계정 휴대폰 · PIN 휴대폰) 같아요. 그 사이 또 넘겼으면 되돌리지 않고 사라져요. 화면 가리기는 넘기기가 아니라서 되돌리기를 띄우지 않아요(가리기를 풀면 멈춘 곳부터 멈춘 채예요. 예전에는 처음부터였어요).

## 3. 지원 범위

| 화면 | 되는 것 |
| --- | --- |
| 교사 화면(PC) + PC가 연 학생 화면 창 | 1–7 전부(‘다음’ 두 단계 · 영상 줄 · K · 5초 되돌리기 · 위치 보존 · 끝 화면 가림) |
| 한 화면 모드(교사 화면과 학생 화면을 따로 쓰지 않음) | ‘다음’ 두 단계(키 · 클리커 · 화면 누르기) · 자동 재생 없음 · 영상 칸 보존 · 위치 보존 · 끝 화면 가림. 일시정지는 화면의 YouTube 단추(교사용 영상 줄 · 되돌리기 없음: 학생도 보는 화면이라) |
| 학생 화면 기기(다른 기기에서 연 학생 화면) | 자동 재생 없음 · 영상 칸 보존. 첫 ‘다음’의 재생 요청을 받으면 그 기기도 틀어 보지만, 그 기기 브라우저가 소리 있는 재생을 막을 수 있어요(4절) |
| 휴대폰 리모컨(같은 계정 · PIN) | ‘다음’ 두 단계(큰 단추가 ‘영상 재생’ → ‘다음’). 영상 대신 카드(“첫 ‘다음’에 재생 · 일시정지는 교사 PC에서”). 넘기기 · 신호등은 영상을 다시 불러오지 않고, 휴대폰으로 넘긴 것도 PC에서 5초 안에 되돌려요 |
| 수업 미리보기 | 학생 화면에 나가지 않아요(예전 그대로). 영상 줄 없음 |
| 준비 화면 · 휴대폰 미리보기 | 영상 카드(재생하지 않아요) |

## 4. 제약(YouTube 정책 · 브라우저)

- **자동 재생 제한**: 소리 있는 영상은, 학생 화면 창에서 사람이 한 번도 누르지 않았으면 재생을 막는 브라우저가 있어요(크롬 · 엣지는 이 사이트 사용 이력도 봐요). 재생을 눌러도 3초 안에 시작하지 않으면 교사 화면이 “학생 화면 브라우저가 재생을 막았어요. 학생 화면(TV)의 영상을 한 번 눌러 주세요.”라고 말해요. 수업 전에 학생 화면 창의 ‘전체 화면’을 누르는 것도 그 창을 누른 것이에요.
- **삽입 금지 · 재생할 수 없는 영상**: 삽입 금지(오류 101 · 150), 없음 · 비공개(100), 주소 오류(2), 이 브라우저에서 재생 불가(5), 플레이어 설정 오류(153)는 교사 화면이 까닭과 ‘YouTube에서 열기’를 보여 주고, 학생 화면은 YouTube 오류 화면 대신 가려요.
- **플레이어가 답하지 않을 때**(학교망에서 YouTube가 막힘 등): 10초 안에 답이 없으면 “학생 화면의 영상과 연결하지 못했어요. 학생 화면에서 영상을 직접 눌러 재생해요.” 되는 척하지 않아요.
- **위치는 이 페이지에만**: 새로고침하거나 학생 화면 창을 다시 열면 링크의 시작 시각(없으면 처음)부터예요. 위치는 초 단위(내림)로 돌아와요.
- **끝난 영상**은 다시 오면 처음부터예요. 일시정지 중에 YouTube가 보여 주는 화면(제목 · 추천 줄)은 YouTube 그대로예요(`rel=0`이라 같은 채널 영상만).
- **소리가 두 번 나지 않게** 교사 화면의 학생 화면 미리보기에는 영상을 넣지 않고 카드만 보여 줘요.
- 시험은 YouTube 메시지를 흉내 내는 가짜 플레이어로 해요(밖으로 나가는 요청 없음). 실제 YouTube · 실제 TV · 학교망에서는 따로 확인해야 해요.

## 6. 남은 과제

- 운영 규칙에 세션 `vid` 칸 배포(교사 승인 뒤, 규칙 먼저).
