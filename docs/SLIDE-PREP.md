# 슬라이드 중심 수업 준비 (2026-11-14, 2단계-2)

1단계 시제품 B(`experiment/original-slides`의 `lab/prep-proto.html`)를 실제 화면에 옮겼어요. 목표는 **올린 자료를 고치지 않고 바로 수업**하는 것이에요.
가져오기는 `docs/SLIDE-IMPORT.md`(2단계-1)를 따라요.

## 화면 (교사 PC, 1101px 이상)

```
| 장면 목록(216px)      | 슬라이드(가운데, 가장 크게)          | 교사 노트 · 핵심 발화 · 더 넣기(340px) |
| 번호 · 작은 그림 · 이름 | 번호 / 장면 이름 · 위아래 · 복제 · 지우기 | 교사 노트(PPTX 발표자 노트)              |
|                      | 슬라이드                            | 핵심 발화(선택)                          |
|                      | (글자 슬라이드면) 슬라이드 제목        | ▸ 더 넣기 · 선택 · 개념 2 · 자료 1 · 도입 · 5분 |
```

- 1400px 이하: 200 · 가운데 · 300. 1100px 이하: 오른쪽 칸이 슬라이드 아래로. 900px 이하: 한 줄로(예전과 같은 순서).
- 글자 크기는 화면 크기에 따라 바꾸지 않아요. 작은 화면에서는 칸 안에서 스크롤해서 닿아요(숨기지 않아요).

## 무엇이 보이고 무엇이 접히나

| 칸 | 어디 | 까닭 |
| --- | --- | --- |
| 슬라이드 | 가운데, 늘 | 교사가 가진 자료가 중심 |
| 교사 노트 | 오른쪽 맨 위, 늘 | PPTX 발표자 노트가 들어오는 곳. 수업 중 교사 화면 · 휴대폰에만 보여요 |
| 핵심 발화 | 노트 아래, 늘 | 선택. 비어도 경고하지 않아요 |
| 핵심 개념 · 단계 · 예상 시간 · 장면 영상 · 수업 자료(신호별) | ‘더 넣기’ 안 | 선택. 이 장면에 넣은 것이 있으면 처음부터 펼쳐져요. 한 번 펼치면 이 창에서는 다른 장면에서도 펼친 채 |
| 장면 이름 · 위아래 · 복제 · 지우기 · 휴대폰 미리보기 | 슬라이드 위 한 줄 | 고칠 때만 |
| 슬라이드 제목 | 글자로 만든 슬라이드 아래만 | PDF 쪽 그림 · 영상 장면에는 쓸 곳이 없어요(예전에는 PDF 장에도 보였어요) |
| ‘+ PPTX에서 노트 붙이기’ | 노트 아래, PDF 수업에 노트가 하나도 없을 때만 | 이미 노트가 있으면 보이지 않아요 |

## 경고는 실제 문제일 때만

- 없앤 것: ‘시작 전 확인’의 **발화 빈 장면 N개**(주황), 장면 목록의 **발화 없음 점**. 선택 항목이 비었을 뿐이에요.
- 남긴 것: 수업 화면 · 모바일 리모컨 상태(없어도 시작할 수 있다고 말해요), 파일이 이 브라우저에 없음, 노트를 붙이지 않은 까닭, 글자만 가져온 수업(PPTX).
- 올린 직후의 알림(올렸어요 · 기본 정리)은 닫을 수 있어요(`notice-x`). 작은 노트북에서 슬라이드를 아래로 밀지 않게. 노트를 붙이지 않았다는 경고와 교사에게 묻는 확인 줄은 닫히지 않아요.
- 기본 정리 안내는 짧게: “기본 정리만 했어요(AI 분석 아님) … 고치지 않고 바로 시작해도 돼요.”(예전: “장면마다 ‘고치기’로 확인해 주세요”)

## 수업 중 교사 화면 · 휴대폰

핵심 발화가 없는 장면(가져온 자료 대부분)은 예전에 “이 장면의 핵심 발화가 없어요”를 띄우고 노트는 아래에 작게 두었어요.
이제는 **교사 노트가 핵심 발화 자리에 크게** 보여요(`note-lead`, 글자 크기 설정을 따라요). 둘 다 없으면 “적어 둔 노트 · 발화가 없어요”만 작게.
수업 화면(TV)에는 노트가 나가지 않아요(예전 그대로).

## 바꾸지 않은 것

데이터 모양(`pages`의 칸), 저장 · 동기화 · 기록 · 복구, 수업 시작 · 수업 화면 열기 · 휴대폰 연결, 예시 원본 읽기 전용. 칸의 id(`pg-{장면}-{칸}`)도 그대로예요.
