# 수업 끝내기 · 학습 상황 체크 (2026-11-15)

새 기능을 따로 만들지 않고, 이미 있는 끝내기 확인 줄 · 신호등 · 수업 자료 · 기록을 이어 붙였어요. 유료 AI는 쓰지 않아요(규칙으로만).

## 수업 끝내기

- **어디서나 보이는 단추**: 교사 화면 머리 오른쪽(‘수업 끝내기’, 깃발 그림), 모바일 리모컨 위쪽 줄(‘끝내기’). 첫 장면부터 있어요. 마지막 장면의 예전 단추도 그대로예요.
- **확인 한 번**: 같은 확인 줄 하나에 `수업 종료` · `계속 수업`. 다음 키 · 클리커 · 수업 화면 누르기로는 여전히 끝나지 않아요.
- 끝나면 예전처럼 기록을 저장하고(같은 수업은 한 건, id = 시작 시각), 수업 화면은 ‘수업 끝’. 휴대폰에서 끝내면 PC가 끝내요(`docs/CLASS-STABILITY.md` 5).
- 수업 미리보기에는 끝내기 단추가 없어요(미리보기 끝내기는 예전대로).

## 신호를 누른 뒤: 지금 쓸 것 (두 개까지)

신호(빨강 · 노랑 · 초록)를 누른 **그 기기**에 짧은 칸이 떠요. 교사 화면은 오른쪽 칸의 수업 화면 미리보기와 ‘다음’ 사이에 들어가요(미리보기만 조금 작아지고, 교사 노트 · 다음 · 영상 단추를 가리지 않아요). 자료 서랍을 열면 접혀요(서랍이 같은 자료를 그 신호에 맞춰 위에 보여 줘요). 휴대폰은 엄지 자리의 신호등 위에 들어가요.

고르는 순서(`suggestFor`):

1. 이 장면에 넣은 자료 중 그 신호의 것(자료의 색 = 신호: 빨강 보충 · 개념 그림 · 오개념, 노랑 예시 · 확인 질문 · 짧은 활동, 초록 적용 · 심화)
2. 이 수업 자료(장면 없이 넣은 것) 중 그 신호의 것
3. 장면의 추천(`rec`, 교사가 고른 것) 중 그 신호의 것
4. 그래도 두 개가 안 되면 **바로 쓸 발문 · 활동** 문장(그 장면의 첫 핵심 개념을 넣어서). 파일이나 링크가 아니에요

- 없는 자료 · 확인하지 않은 링크를 만들지 않아요. 1–3은 교사가 넣은 자료뿐이에요.
- **수업 화면은 교사가 ‘띄우기’를 누를 때만** 바뀌어요(다시 누르면 내리기). 발문은 말로 묻는 것이라 띄우기가 없어요(자료 서랍과 같아요).
- 같은 신호를 다시 누르면 신호도 칸도 지워져요. 장면을 넘기거나 ×를 누르면 닫혀요(신호는 그대로).
- 발표 설정에서 학생 반응을 끄면 칸도 나오지 않아요.

## 수업 뒤 기록과 이어지는 것

- 신호는 예전처럼 장면별로 기록에 남아요(`events`). 빨강으로 끝난 장면은 기록의 ‘다시 지도할 것’ · ‘보충할 장면만’ 거르기로 이어져요(`docs/RECORDS.md`).
- 띄운 자료는 기록의 ‘보여 준 자료’에 남아요(`used`). 칸에 떴다는 것만으로는 남기지 않아요.
