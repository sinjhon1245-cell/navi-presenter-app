# 수업 내비 — 화면·기능·데이터

## 세 화면 (용어)

| 화면 | 기기 | 보여 주는 것 |
| --- | --- | --- |
| 학생 화면 | TV · 전자칠판 | 슬라이드만. 띄운 수업 자료, 타이머, 번호 뽑기가 위에 겹쳐 뜸. 왼쪽 1/3을 누르면 이전. 교사용 발화·메모·반응은 보이지 않음 |
| 교사 화면 | 노트북 · PC | 맨 위 장면 진행(‘06 / 12 장면’ · 경과 시간 · 장면 막대 · 얇은 시간 막대), 핵심 발화, 학생 화면, 다음 장면, 신호등, 수업 자료. 한 화면에 스크롤 없이 |
| 휴대폰 리모컨 | 교사 휴대폰 | 위쪽 장면 번호(‘06 / 12’) · 수업 시계 · 얇은 장면 막대, 핵심 발화(크게), 신호등, 학생 화면·다음, 아래 엄지 줄 [이전][목차][자료][다음] |

교사 화면이 학생 화면 창을 직접 열어 그린다(`window.open` + 같은 페이지에서 렌더). 기기끼리는 PIN 4자리로 묶인 수업 진행 상태를 실시간으로 공유한다(1단계부터).
‘수업 미리보기’는 다른 기기에 보이지 않고 기록되지 않는다. 휴대폰에서는 휴대폰 리모컨 화면으로 미리 본다.

## 수업 준비 (교사 화면)

- 맨 위 줄: 수업 제목 · 직접 제작한 예시/내 파일 · 학년 교과 · 장면 수 · 시간 · 저장 상태 · 수업 바꾸기 · 수업 미리보기 · 수업 시작
- 탭 1 **수업 흐름**
  - 처음 열면 **내 수업**(2026-11-11, `docs/MY-LESSONS.md`): 내 수업 목록(열기 · 복제 · 삭제), 새 수업 만들기(빈 장면 1개), 예시 수업 둘러보기, 내 수업 파일 불러오기(PDF·PPTX), 최근에 연 예시 · 파일
  - **예시 수업**(따로 둔 메뉴): 직접 제작한 예시 수업 카드, 학년·교과 거르기, 고른 수업 요약. 예시 원본은 읽기 전용이고 ‘수정해서 사용하기’로 내 수업에 복제해 고쳐요
  - 시작 전 확인 줄: 수업 화면 상태, 모바일 리모컨 연결(2026-11-14부터 ‘발화 빈 장면’은 경고하지 않아요, `docs/SLIDE-PREP.md`)
  - 3열(2026-11-14, `docs/SLIDE-PREP.md`): 왼쪽 장면 목록(작은 슬라이드 그림 · 도입·전개·정리) / 가운데 슬라이드(가장 크게)와 장면 이름 / 오른쪽 교사 노트 · 핵심 발화, 접힌 ‘더 넣기’(핵심 개념 · 단계 · 예상 시간 · 장면 영상 · 이 장면의 수업 자료: 신호별로 묶음, ‘보기’로 수업 화면 미리보기)
  - 교사 화면(PC)에서는 화면 전체가 길어지지 않고 칸마다 스크롤
- 탭 2 **발표 설정**: 화면(교사 화면·학생 화면·휴대폰 리모컨 상태), 휴대폰 리모컨(QR), 프롬프터, 수업 중(수업 자료 개수, 신호등, 늦어지면 알림, AI), 우리 반, 색, **초기화**
- 탭 3 **수업 기록**(`docs/RECORDS.md`): 이 수업 / 전체 / 휴지통, 제목 검색 · 기간 · 학년 · 교과 · 보충할 장면만, 펼치면 시작 · 끝 시각, 장면별 이해도와 시간 표, 다시 지도할 것 · 질문 메모(고치기), 사용한 자료, 교사 메모(수정 가능), 글로 복사, 휴지통으로(30일 안에 되살리기). 아래에 ‘예시 기록’ 3건

## 핵심 동작

- **수업 자료 올리기**: PDF(장 그림 + 글자, 파일 하나에 최대 40장), PPTX(글자 + 발표자 노트, 그림 · 글꼴 · 배치 · 애니메이션은 옮기지 않음). 둘 다 올리면 PDF 위에 노트를 붙임. 파일 하나 100MB까지, 원본은 이 브라우저(IndexedDB)에 저장하고 수업에는 파일 id만(`docs/LOCAL-FILES.md`). 새 내 수업으로 만들거나, 지금 내 수업 뒤에 장면으로 더하거나, 장면의 수업 자료로 첨부(그림 PNG · JPG · GIF · WebP · PDF · PPTX)
- **AI 분석**(업로드 직후 자동, AI 연결 시): 장마다 label, stage, min, concepts(≤3), say(≤2), notes, rec(목록 안 id ≤2), want. AI가 없으면 ‘기본 정리’(장 순서로 단계 나누기)
- **신호등(학생 반응)**: 교사가 지금 장면에 대한 학급 전체의 이해를 한 번 눌러 기록. 빨강 다시 설명이 필요해요 / 노랑 조금 더 확인해요 / 초록 잘 이해했어요. 다른 색을 누르면 최신 판단으로 바뀌고, 같은 색을 다시 누르면 지워짐. 누른 순서는 모두 남음. 학생 개인 평가가 아니라 수업 관찰 기록이며 학생 정보는 저장하지 않음
- **질문 메모**: 신호등과 따로, 장면마다 짧은 글로 남김
- **수업 자료 추천**: 자료마다 맞는 신호(`lv`)가 있음. 빨강 → 보충 설명·개념 그림·오개념 확인, 노랑 → 추가 예시·확인 질문·짧은 활동, 초록 → 적용 활동·심화 질문·확장 과제. 신호를 누르면 맞는 자료가 ‘추천’으로 위로 옴. 학생 화면은 교사가 ‘학생 화면에 띄우기’를 눌러야만 바뀜
- **영상 장면**: 장면에 YouTube 링크를 넣으면 그 장면은 학생 화면에 영상으로 떠요. 자동 재생 없음, **첫 ‘다음’ = 영상 재생 · 둘째 ‘다음’ = 다음 장면**(교사 PC · 휴대폰 같음, 세션 `vid`), 교사 화면 영상 줄의 재생 · 일시정지(K), 재생 중 넘기면 5초 동안 ‘이전 장면으로 되돌리기’(U, 장면 이동 취소), 돌아오면 멈춘 곳부터 멈춘 채, 끝나도 다음 장면으로 넘어가지 않음(`docs/VIDEO.md`)
- **꺼내고 돌아오기**: 학생 화면에 띄운 자료는 다음 키 한 번에 닫히고 슬라이드로. 수업용 카드·그림은 학생 화면 가득, 그림 파일은 그림, 유튜브는 영상(멈춘 채 뜨고 교사 PC의 재생 · 일시정지로, `docs/VIDEO.md`), PDF 파일은 PDF 보기, PPTX 파일은 장 제목 글자 카드(‘글자만’), 그 밖의 링크와 내용 없는 자료는 제목만. 이 브라우저에 없는 파일은 그 자리에 ‘파일이 없어요’ · 휴대폰은 ‘교사 PC에만 있어요’
- **키**: 다음 → ↓ 스페이스 엔터 PageDown / 이전 ← ↑ 백스페이스 PageUp / B·W 화면 가리기 / 1·2·3 신호등(빨강·노랑·초록)
- **수업 기록**: 끝내기 때 자동 생성(수업 시작 시각으로 만든 id라 한 번만). 이 브라우저에 먼저, 로그인한 교사 PC는 계정에도. 다음에 같은 수업을 열면 첫 장면 프롬프터에 지난 메모
- **초기화**: ‘처음부터 다시 시작’(장면·자료 유지, 진행 시간·지금 장면·반응만 처음으로, 진행 중 기록은 저장 또는 버리기 선택, 끝난 기록은 유지)과 ‘수업 자료 초기화’(고친 내용을 처음 상태로, 내가 넣은 자료는 보관함에 남길 수 있음, 수업 중에는 안 됨)
- **연결이 없을 때(지금 배포)**: 휴대폰·다른 기기 연결과 AI는 “연결 전”으로 표시. 수업 기록과 내 수업은 이 브라우저(IndexedDB)에만 저장, 올린 파일 원본도 이 브라우저(IndexedDB `navi-files`)에만 저장(다른 기기에는 없음)

## 데이터 (시안의 문서 모양 그대로 + 추가)

- `lessons/deck`: `{ v, kind: "example"|"sample"|"pdf"|"pptx", key, oldKeys?, lessonId?, title, tag, grade?, subject?, total, srcLink?, prep?: "ai"|"basic", pages[], res[] }`
  - page: `{ id, n?, stage, label, min, notes, concepts[], say[], rec[], want, url?, aid?, ar?, text?, title?, lines?, layout? … }`
  - res: `{ id, scene ("" = 보관함), t: 보충|영상|활동|발문|평가, lv?: red|yellow|green, s: mine|ex|peer|viva, title, note, link, aid?, mt?: "image"|"pdf", card? }`
  - `card`: 학생 화면에 보여 줄 수업용 카드 `{ layout, eye, title, items|rows|choices|defs|sub }` 또는 그림 `{ pic }`(lessons.js의 그림 이름)
- `lessons/settings`: `{ monitor, presenter, strength, reactions, ai, theme, palette, pin, className, classSize, fontSize, showConcepts, showNotes, showNext, pace, tapNav }`
- `sessions/s{PIN}`: `{ v, started, ended, cur, t0, enteredAt, log[{id,sec}], reactions[{id,type,at}], qs[{id,text,at}], used[], tv, blank, tool, memoId }`
  - `reactions[].type`: `red | yellow | green | clear` (옛 `confused`→빨강, `good`→초록, `questions`→질문 메모로 읽음)
- `memos/{id}` (v2): `{ v: 2, key, title, grade, subject, cls, at, totalSec, plannedMin, again[], used[], usedTitles[], scenes[{label,min,sec,sig}], sig{red,yellow,green}, questions[{label,text}], events[{label,type,at}], text }`
  - 옛 기록의 `rc{confused,good,questions}`도 읽어서 보여 줌
- 내 수업(2026-11-11): 로그인한 교사 PC는 `teachers/{UID}/decks/{m-…}`(지금 수업과 같은 모양 + `kind: "mine"` · `myId` · `from` · `at` · `made`), 아니면 이 브라우저 `lessons`의 `m-…` 줄
- 이 브라우저 저장(IndexedDB `navi-local`): `records`(수업 기록, `local-…` id), `lessons`(최근에 연 예시 · 파일, 로그인하지 않았을 때의 내 수업, 2026-11-11 전에 고친 예시 수업의 글자 — 지우지 않고 ‘내 수업’으로 옮길 때 `movedTo`를 적어요)

## 예시 수업 · 비바샘

예시 수업 5개와 예시 기록 3건은 `public/lessons.js`에 있다. 직접 만든 수업이며 ‘직접 제작한 예시 수업’으로 표시한다.
